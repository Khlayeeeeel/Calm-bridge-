# CalmBridge Kindred Companion

## Platform Overview
CalmBridge Kindred Companion is a comprehensive mental health support platform designed to foster connection and understanding between Children, Parents, and Doctors. By providing tailored interfaces and tools for each stakeholder, the platform bridges communication gaps and promotes proactive mental wellness management.

## Key Features

### Role-Based Dashboards
The platform provides distinct, purpose-built dashboards for each user type:
- **Child Dashboard**: A gamified, engaging interface that makes mental health tracking approachable. Features include mood logging, activity suggestions, and direct access to the AI companion.
- **Parent Dashboard**: A monitoring and management hub for parents to oversee their child's progress, view health reports, and manage appointments.
- **Doctor Dashboard**: A clinical view for healthcare professionals to review patient data, track progress over time, and manage treatment plans.

### AI Companion & Support
- **AI Chatbot**: An always-available, empathetic AI companion that provides immediate support, coping strategies, and a safe space for users to express their feelings.
- **Smart Analysis**: The AI helps identify trends in mood and behavior to provide actionable insights.

### Wellness Tools
- **Activity Manager**: A curated list of wellness activities designed to improve mental state.
- **Mini-Games**: Interactive tools to help users manage stress and anxiety:
  - **Breathing Game**: Guided breathing exercises for relaxation.
  - **Color Game**: A soothing visual activity to shift focus and reduce stress.
  - **Memory Game**: Cognitive engagement to distract from anxious thoughts.

### Communication & Management
- **Secure Chat System**: Facilitates safe and private communication between children, parents, and doctors.
- **Child Calendar**: Helps organize schedules, appointments, and wellness routines.
- **Doctor Rating System**: meaningful feedback loop for healthcare providers.

### Health Tracking
- **Health Monitoring**: Tracks vital metrics and mood trends over time.
- **Progress Reports**: Detailed reports that visualize progress, identifying areas of improvement and concern.

## Technology Stack
This project is built with:
- **Frontend Framework**: React + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn-ui + Lucide React
- **Icons**: Lucide React

## Getting Started

### Prerequisites
- Node.js & npm installed

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd calmbridge-kindred-companion-main

# Install dependencies
npm i

# Start the development server
npm run dev
```
